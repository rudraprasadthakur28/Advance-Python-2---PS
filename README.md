# Advanced Python 2 Practice Set

This repository contains solutions to the Advanced Python 2 Practice Set.

The practice set focuses on virtual environments, Python package management, string formatting, functional programming, and creating a basic web server using Flask.

## Practice Problems

### 1. Create Similar Virtual Environments

Create two virtual environments and install a few packages in the first environment.

Create a similar environment in the second environment using the package information from the first environment.

Concepts practiced:

- Virtual environments
- `venv`
- `pip`
- `pip freeze`
- `requirements.txt`

### 2. Format Student Information

Write a program to input the name, marks, and phone number of a student and format the information using the `format()` method.

Expected output:

```text
The name of the student is Harry, his marks are 72 and phone number is 99999888
```

### 3. Convert Multiplication Table to Vertical String

A list contains the multiplication table of 7.

Write a program to convert the list into a vertical string containing the same numbers.

Example:

```text
7
14
21
28
35
42
49
56
63
70
```

### 4. Filter Numbers Divisible by 5

Write a program to filter a list of numbers and return only the numbers that are divisible by 5.

Concept practiced:

- `filter()`
- Lambda functions

### 5. Find Maximum Using `reduce()`

Write a program to find the maximum number in a list using the `reduce()` function.

Concept practiced:

- `reduce()`
- Lambda functions
- `functools`

### 6. Create a Virtual Environment from `pip freeze`

Run `pip freeze` for the system Python interpreter.

Take the package information and use it to create a similar virtual environment.

Concepts practiced:

- `pip freeze`
- Virtual environments
- `requirements.txt`
- Installing dependencies

### 7. Create a Flask Web Server

Explore the Flask module and create a basic web server using Flask and Python.

Concepts practiced:

- Flask
- Python web development
- Web server
- Routes
- Basic HTTP requests

## Concepts Practiced

- Virtual Environments
- `venv`
- `pip`
- `pip freeze`
- `requirements.txt`
- `format()`
- `join()`
- Lambda Functions
- `filter()`
- `reduce()`
- Flask
- Basic Web Development

## Learning Goal

The goal of this practice set is to apply Advanced Python concepts through practical exercises and get an introduction to Python package management and web development with Flask.
